# assets

A storage repository for image assets. It contains no source code; the images are kept here so they can be referenced by URL from other projects.

## Contents

| Path | Description |
| --- | --- |
| `featured/` | Featured banner images (`Featured.png`, `Featured2.png`) and alternate versions with a `w` suffix (`Featuredw.png`, `Featured2w.png`). |
| `featured2/` | A second set of featured banner images (`Featured.png`, `Featured2.png`). |
| `images/bible_hindi/` | Five numbered images (`one.jpg` to `five.jpg`) for Hindi Bible content. |
| `images/bible_sadri/` | Five numbered images (`one.jpg` to `five.jpg`) for Sadri Bible content. |
| `images/gideons/` | Images grouped by prefix (`ba (1).jpg`, `ba (2).jpg`, `hi (1).jpg` to `hi (3).jpg`) for Gideons content. |
| `images/jewellery/` | Four numbered jewellery images (`one.jpg` to `four.jpg`). |
| `images/updates/` | Update and seasonal banners: Christmas variants of the featured images and a "Kids Corner" graphic in PNG and SVG. |
| `images/verse_images/` | Numbered verse images (`1.png` to `15.png`; `6.png` is not present). |
| `images/featured` | A small placeholder text file, not an image. |

## Usage

Files can be referenced through their raw GitHub URLs, for example:

```
https://raw.githubusercontent.com/TIRK3Y/assets/main/images/verse_images/1.png
```
